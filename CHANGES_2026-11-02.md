### 1.2 What the new counting game does differently

Behavior changes you should know about before deploying:

- **Saves are now server-wide, not per member.** One shared bank. The server
  earns one save each time the count reaches a multiple of the interval (default
  50: at 50, 100, 150...). The bank has a cap (default 3).
- **Saves are off by default** per server. Turn them on with
  `/counting save-config enabled:True` or the dashboard checkbox. Existing
  servers start with saves off after upgrade.
- **Plain whole numbers only.** Math expressions like `7*6` no longer count.
  Anything that isn't just digits is ignored as ordinary chat.
- **Removed features:**
  - `/counting calc` (the expression calculator)
  - `/counting milestones` and the dashboard "Milestone reactions" card
    (bonus emoji on 67 / 100 / 1234 / 2024)
  - `/counting savemilestone` (replaced by `/counting save-config`)
  - per-member lifetime counts and personal save balances
- **Slash commands now:** `channel`, `current-number`, `saves`, `save-config`,
  `highscorealerts`.
- Messages are judged in one step in `Db.apply_count_attempt` instead of an
  asyncio lock in the cog, so two near-simultaneous messages can't read the same
  number.
- The reply messages were reworded and now say what count was lost on a reset.

### 1.4 Licensing / headers

Every itsfanno file begins with a header saying it is used under an Individual
Proprietary Use License. That header was **removed** from everything copied
into main. Reason: main is your AGPL-3.0 tree and you hold the copyright, so
the per-licensee notice doesn't belong there. The itsfanno license itself
(section 8) says the public repo stays AGPL.

One thing to be aware of: that license is written for the *licensee's* use of
your code. If any of the counting rewrite was written by itsfanno rather than by
you, check that you're comfortable folding it into your repo, since they may
hold rights to their own changes. I couldn't tell authorship from the files.

## 2. AutoMod invite-link controls

### 2.1 Before

`/automod invites on|off` and one dashboard checkbox. When on, **every** Discord
invite was deleted and counted as a strike, including your own server's, partner
servers, and invites in a channel meant for advertising. No exceptions.

### 2.2 Now

Four new controls, all default to **exactly the old behavior**, so nothing
changes until you configure it.

| Control | Options | Default |
|---|---|---|
| Action when caught | `strike` (delete + count toward the punishment ladder), `delete` (delete + log, no strike), `log` (leave the message up, just log it) | `strike` |
| Allow this server's own invites | on / off | off |
| Allowlist | an invite code, an invite link, or a server ID | empty |
| Exempt channels | any text channel | none |

Details of how it behaves:

- **Allowlisted server ID** lets through every invite that points at that
  server. The bot looks the invite up with Discord and caches the answer for 10
  minutes. A lookup only happens if you actually configured a server allowlist
  or "allow own server"; otherwise there is no network call at all.
- **Allowlisted invite code** is matched **exactly, case-sensitive** (Discord
  codes are case-sensitive, so `abc` and `ABC` are different invites).
- **Your own vanity URL** is recognized without a lookup.
- An invite that **can't be resolved** (dead invite, Discord error) is blocked
  unless its exact code is allowlisted. A temporary Discord error is not cached.
- If a message has several invites, it's blocked if **any** of them is not
  allowed.
- In `log` mode the message stays up and the rest of AutoMod still runs on it.
- Administrators and AutoMod exemption roles stay exempt, as before.
- Allowlist is capped at 100 entries per server.
- Dashboard actions and slash-command changes are recorded as bot events.
- The dashboard's **snapshot restore** now also restores action mode and the
  own-server toggle when a snapshot contains them. Older snapshots leave current
  values untouched. The allowlist and exempt channels are **not** part of
  snapshots.

### 2.3 How to use it

Slash command (one command, all options optional, Manage Server needed):

```
/automod invitesettings mode:<strike|delete|log> allow_own_server:<bool>
    allow:<link, code or server id>  unallow:<...>
    exempt_channel:<#channel>  unexempt_channel:<#channel>
```

Run it with no options to see the current settings. The dashboard has the same
controls under Automod > Invite links.

## 5. Reverting

From the repo root, to undo everything in this change log:

```
patch -R -p1 < reedmuhn-changes.patch
```

The patch uses `a/` (original main) and `b/` (this version) paths, so `-p1`
from the repo root is right. To apply the whole change to a clean copy of the
main repo instead, drop the `-R`. The original counting files are also in
`counting-backup-original-files/`. To revert only counting, restore those files
and delete `tests/test_counting_saves.py`.
