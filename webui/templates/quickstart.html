Quickstart

{% if staff %}

Your staff access

  1. Moderation: look up a member, add or remove warnings, edit or void cases, purge messages, lift tempbans.
  2. Moderation Queue: approve or deny actions waiting for a decision.
  3. Reports, Tickets, Modmail, Suggestions: triage what members send in.
  4. Search: find a member or case fast.

Settings pages are hidden for staff. Ask the owner if you need something changed.

{% else %}

Get running in 10 minutes

  1. Check the boot report. Set BOOT_LOG_CHANNEL_ID in .env to a private channel. Each restart the bot posts every cog file it loaded, with ✅ or ❌ and the error if one failed.
  2. Pick who sees this dashboard. Dashboard Access: leave it open to Administrators, or narrow it to just you. Add moderators as Staff.
  3. Turn on logging. Logging → auto-create channels so you can see what happens.
  4. Protect the server. AutoMod, Raid Detection and Anti-Nuke.
  5. Welcome people. Welcome & Roles and Verification.
  6. Add what you want. Tickets, reaction roles, leveling, music... everything else is optional and lives in the menu on the left.

Turn a feature off completely with DISABLED_COGS in .env (e.g. DISABLED_COGS=music,fun). The full guide is docs/QUICKSTART.md in the bot's folder.
