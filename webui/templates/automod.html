Warning window

Every removed message counts as one warning. This is how long (in seconds) recent warnings stick around before they age out and stop counting toward the escalation tiers below.

Escalation tiers

Pick what happens once a member racks up a given number of warnings within the window above. Add as many tiers as you like - e.g. 3 warnings → warn, 5 → mute, 8 → kick, 12 → ban. Reaching a mute/timeout/kick/ban/temp-ban tier resets the member's warning count back to zero; a "Warn" tier logs a formal warning (visible on the Moderation tab) but leaves the count running, so it doesn't delay the tiers above it.
