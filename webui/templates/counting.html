Server saves

When saves are on, the whole server earns one save each time the count reaches a multiple of the number below (for example 50, 100, 150). After a reset the server has to climb back up to earn another. If someone miscounts and the server has a save banked, the save is spent and the count carries on instead of resetting.

High score alerts

Off by default. /counting current-number always shows the high score on request either way.
